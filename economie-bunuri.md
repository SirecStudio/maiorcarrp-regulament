# Economie si Bunuri

## 1. Tranzactii

Tranzactiile intre jucatori trebuie sa fie justificate roleplay. Inselatoriile pot fi permise doar daca sunt roleplay coerente si nu exploateaza mecanici sau increderea OOC.

## 2. Transferuri intre personaje

Transferul de bani, iteme sau proprietati intre propriile personaje este interzis fara aprobare staff.

## 3. Bunuri pierdute

Bunurile pierdute din cauza bugurilor pot fi returnate doar cu dovezi clare. Staff-ul nu este obligat sa compenseze pierderi fara probe.

## 4. Economia serverului

Manipularea economiei prin exploituri, metode repetitive nerealiste sau intelegeri OOC este interzisa.
