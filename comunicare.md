# Comunicare si Comportament

## 1. Limbaj

Limbajul vulgar moderat poate exista in roleplay daca se potriveste scenei, dar atacurile personale, injuriile excesive si jignirile in afara caracterului sunt interzise.

## 2. OOC si IC

Separarea dintre OOC si IC este obligatorie. Conflictele dintre personaje nu trebuie transformate in conflicte personale intre jucatori.

## 3. Voice chat

Microfonul trebuie folosit corespunzator. Sunetele deranjante, muzica redata pe voice, tipetele constante sau folosirea voice changer-ului abuziv pot fi sanctionate.

## 4. Discord

Canalele Discord trebuie folosite conform destinatiei lor. Ticket-urile, reclamatiile si solicitarile catre staff trebuie formulate clar si cu dovezi cand este cazul.
